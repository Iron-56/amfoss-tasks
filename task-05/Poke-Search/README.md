## Pokémon Rescue

Firstly, I was able to fetch the data by using get function of request and converting it to a json format. By passing the limit as -1 I was able to get all the pokemon details in their api. I displayed the name, abilities and types in the search window and stats in another window using QLabel and using a similar approach to the window created by in search window class (QVBoxLayout). I also did a loading aniation using the landing gif provided while the image of the pokemon was being fetched from the api. To do so I had to make another thread so that the movie (gif) won't get stuck. To capture the pokemon, I first check if the folder exists and if not I made a folder at assests/captured where the pokemon image will be saved using pixmap.save function and os.mkdir for folder creation. To display the captured pokemons, i used QVBoxLayout class and inserted the pixmap, name of pokemon, previous and next buttons. To do so, I first sorted the images using sorted(os.listdir("assets/captured")) and I used an index variable which would cycle through the array. The program also contains invalid input handling such as when a non existant pokemon is searched or when trying to display the captured pokemon if no pokemons are captured. I was also able to set the styling of the widgets using setStyleSheet, setAlignment, setScaledContents and setScaledContents functions.
